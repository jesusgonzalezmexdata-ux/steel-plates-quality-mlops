Which defect does each steel plate have, and when should a person check?

Seven defect types, 27 measurements per plate. A frozen model classifies the defect, and a review rule decides which predictions go to an inspector.

How the decision was made

  1. Data contract and leakage audit on the public dataset.
  2. Stratified split; cross-validation on training only.
  3. Baseline, candidates and controlled tuning; model frozen before the holdout.
  4. One holdout evaluation, error analysis and an assumption-based review policy.

What it does not claim

  • Every plate in the data is already defective: it classifies defects, it does not predict them.
  • The 0.80 review threshold is development-only and not validated prospectively.
  • Costs are assumptions you supply, not plant data.
